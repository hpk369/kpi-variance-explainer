How it works

  1. A daily pipeline builds bronze → silver → gold Delta tables from synthetic banking data, with data-quality rules and a GL reconciliation control.
  2. Six governed SQL functions in Unity Catalog are the agent's only way to get a number. Arguments are bound parameters, so the model can't write SQL.
  3. RAG over the glossary (Vector Search) supplies the definitions the answer uses: the same definitions the SQL and the Power BI measures follow.
  4. A number check matches every figure in the draft to a tool result. A mismatch sends the draft back; after two retries the commentary is withheld and only the tool tables are shown.
  5. MLflow evaluation scores 15 questions with planted answers: number accuracy, tool selection, groundedness and retrieval relevance (LLM judge), and guardrails.
